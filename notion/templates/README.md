# Notion DB 既定テンプレート（正本）

このディレクトリは、Notion の3つのDB（タスク／エピック／レビュー）の既定テンプレート本文の正本です。

| ファイル | 対象DB |
|---|---|
| `task.md` | タスク |
| `epic.md` | エピック |
| `review.md` | レビュー |

## 設定方法

本文の反映は `ntn pages edit <設定に書いたページ ID> < このファイル` で行います。テンプレートの新規作成と「既定にする」の切り替えだけは API にエンドポイントが無いため、UI で行います。

タスクとエピックの行の作成は `scripts/create_row.py` が行います。DB の既定テンプレートを実行時に取得して適用し、本文の穴を埋め、作成後に読み返して検査します（API でも既定テンプレートは適用できます）。このディレクトリのファイルは正本ですが、`create_row.py` は文面ではなく構造（見出し名と表の行ラベル）で穴を探すので、テンプレートの文面を変えても動きます。

テンプレートのページ ID は環境ごとに違うので、このリポジトリには書きません。環境の設定(`envs/<名前>.toml`)の `[notion]` に、次のキーで書きます(任意)。

| 対象DB | 設定のキー |
|---|---|
| タスク | `task_template` |
| エピック(既定にするもの) | `epic_template` |
| レビュー | `review_template` |

既定にしたいテンプレートは、DBを開いて「新規」の右の ▼ → テンプレート → 対象の「…」→ 既定に設定、で切り替えます。。本文には環境ごとの値(`${repo_url}` など)が入るので、`make render` で作った `build/<環境>/notion/templates/*.md` を貼る

## 運用

- 変更はまずこのディレクトリのファイルを直す。
- 変更したら、3つのDBのテンプレートも同時に直す（正本とUIをずらさない）。
